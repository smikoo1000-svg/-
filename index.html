🎹 Music to Piano

음악 파일을 올리면 음을 분석해 피아노 연주로 바꿔줍니다. 모든 처리는 브라우저 안에서 이루어지고 파일은 업로드되지 않습니다.

💡 고정밀 모델 안내: 현재 웹 브라우저 버전은 빠른 변환을 위한 근사치 알고리즘을 사용합니다. AI(Demucs, Basic Pitch)를 활용한 100% 원곡에 가까운 고품질 변환을 원하신다면 고성능 파이프라인 버전으로 이동해 주세요!
오디오 파일을 끌어다 놓거나 클릭해서 선택 (mp3, wav, m4a, ogg)

변환하면 악보가 여기에 표시됩니다.

방식: STFT → 하모닉 합산 음높이 점수 → 배음 제거를 반복하는 다성 추정 → 음 추적 → 피아노 합성. 단일 악기나 피아노곡에 가장 정확하고, 여러 악기가 섞인 곡은 근사치입니다.
